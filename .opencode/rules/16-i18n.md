# Internationalization (FR + EN)

The app ships **French and English** from day one. French is the primary language.

## Setup (verified against Flutter 3.47.6 / `gen-l10n`)

- **ARB sources:** `lib/l10n/app_en.arb` (template) + `lib/l10n/app_fr.arb`.
- **Config:** `l10n.yaml` pins `arb-dir: lib/l10n`, `output-dir: lib/l10n/generated`, `output-class: AppLocalizations`, `nullable-getter: false`. `output-dir` is explicit on purpose — the default generated location has moved between Flutter releases, and a moving path is a latent break in every import.
- **`pubspec.yaml` requires `flutter: generate: true`.** Without it `flutter gen-l10n` produces code that cannot be imported and exits non-zero.
- **Do not put `synthetic-package` in `l10n.yaml`.** It is a no-op in this Flutter version and emits a deprecation warning on every run.
- **Wiring:** `flutter_localizations` delegates and `supportedLocales` are set in `lib/main.dart` from `AppLocalizations.localizationsDelegates` / `.supportedLocales`; locale resolution is handled by a `localeListResolutionCallback` (the preferred API — `localeResolutionCallback` only sees the first preferred locale).
- **Import path:** `package:lumen_tale/l10n/generated/app_localizations.dart`. The import shown in gen-l10n's own generated doc comment (`generated/app_localizations.dart`) violates `always_use_package_imports`; do not copy it.
- Regenerate with `flutter gen-l10n` after editing any ARB file. Run `flutter analyze` — it flags missing keys on the code side.

## Rules

1. **No hardcoded user-visible strings** in widgets — ever. Every label, button, tooltip, empty-state, error message and semantics label goes through `AppLocalizations.of(context)`.
2. **Every new string** is added to **both** ARB files in the same commit. Keep `@@locale`, `@key` metadata blocks, and `placeholders` consistent between the two files — an entry present in one file and missing in the other is a defect, not a fallback.
3. **Keys are prefixed by feature and describe meaning, not layout**: `navLibrary`, `libraryEmptyTitle`, `readerErrorBody`. **Not** dot-namespaced — `gen-l10n` flattens keys into camelCase getters, so `library.emptyTitle` does not become a namespaced getter. Never translate a key twice; one concept, one key.
4. **Dynamic text**: chapter and novel titles are source data, not localized. Format dates and numbers with `intl` `DateFormat` / `NumberFormat` for the active locale.
5. **Unsupported locales resolve to French.** `_resolveLocale` in `lib/main.dart` matches any preferred locale by language code and returns `Locale('fr')` when nothing matches. This is deliberate — French is the project's primary locale, so an unknown system locale must not silently fall back to the ARB template (`en`).
6. **Plurals and placeholders** use ICU syntax (`{count, plural, ...}`) and must be declared identically in both files. `chapterCount` is the reference example.
7. **Semantics labels are localized too** — see `coverSemanticsLabel` and `14-design-tokens.md` §Accessibility.
